相控与 PWM 的控制特点

两个时钟

3.33 ms相控：一个换相点的间隔
50 µsPWM：一个开关周期（20 kHz）

同一台他励直流电机，要从额定转速降到 40%。相控让晶闸管在电网的换相点上等一等再点火；PWM让 IGBT 每 50 µs 重新决定一次通断比例。两者输出的平均电压可以完全相同，但控制量、线性度、响应速度、谐波位置和代价，全都由这两个时间刻度推出来。

两个时钟 / 01 · 控制自由度01 / 09

01 从器件开始

开关只被允许做两件事

变换器的全部本事，是把开关按某个节奏通断，从电源里切出想要的电压。节奏能有多细，取决于器件让不让你随时关断——这一步决定了你手上到底有几个可调的量。

晶闸管是半控型器件。阳极承受正向电压时，门极给一个触发脉冲就能让它导通；一旦导通，门极就失去作用，只有阳极电流降到维持电流以下——通常是电源电压反向、电流自然过零——它才关断。开通可以选，关断不能选，所以能调节的只剩下开通的时刻。

IGBT、MOSFET 是全控型器件。栅极既能开通也能关断，开关时刻完全由控制器决定，不必等电网。于是同一只开关上多出一个可调的量：不只是“什么时候开”，还有“开多久”和“开多密”。PWM 的一切特点，都是从这多出来的一维里长出来的。

01 / 半控

控制量：一个相位

触发延迟角 α 相对自然换相点计算。改变 α 就是挪动“开”的时刻，关断时间由电路自己决定。

02 / 全控

控制量：一个比例

占空比 D 是导通时间占开关周期的比例。改变 D 不挪动相位，只改变一个周期内的“开”与“关”的配比。

03 / 共同点

分辨率就是时间

两种方式的可调精度，最终都换算成时间：相控的最小步长是换相间隔，PWM 的最小步长是开关周期。

相控与 PWM 的分野，不在电路拓扑，而在器件有没有关断权。

两个时钟 / 02 · 相控02 / 09

CLOCK A 相控 · Phase Control

等一个换相点

三相全控桥的自然换相点每 3.33 ms 出现一次，也就是每 60° 电角度一次。你能做的只有决定在哪个换相点点火，然后等电流自己过零。所谓“连续调压”，其实是每 3.33 ms 做一次离散的决定。

触发脉冲必须与电网电压同步，从自然换相点起延迟一个电角度 α 再触发，α 称为触发延迟角。大电感负载下，输出电压的平均值严格等于 Ud = Ud0cosα：α 越大，截取的正弦波段越靠后，平均值越低。

这条余弦关系带来两个后果：一是增益 Ud0sinα 随工作点变化，轻载与深调压时环路增益差很多；二是 α 一旦触发就不能改，必须等到下一个换相点，这段等待就是失控时间，最大 3.33 ms、平均 1.67 ms。

01

必须与电网同步

α 是相对自然换相点定义的，控制电路要先知道电网相位。同步变压器或锁相环一旦失锁，触发就会错位，输出电压跟着乱。

02

余弦非线性

Ud = Ud0cos α，增益 −Ud0sin α 随 α 变化。工程上用余弦移相把 α 反算成控制电压，才能得到近似线性的刻度。

03

离散的响应

两次触发之间改不了主意。三相桥的失控时间最大 3.33 ms，在控制环里通常近似成一阶惯性环节，带宽做不到很高。

相控不是“连续调压”，是每 3.33 ms 做一次决定。

两个时钟 / 03 · PWM03 / 09

CLOCK B PWM · Pulse Width Modulation

自己敲拍子

全控器件把关断权交回控制器。于是“调压”变成了“调一个周期里导通占多少”，而“波形好不好”这个问题，被整个搬到了频域。

PWM 的合法性来自面积等效原理：冲量相等而形状不同的窄脉冲，加在有惯性的环节上，产生的效果基本相同。把正弦半波切成若干份，每一份用一个面积相等的等高矩形脉冲代替，负载“感觉”到的仍然是同一条正弦——这就是 SPWM。

占空比 D = Ton/Ts。Buck 斩波 Uo = D·Ui，SPWM 线性区 U1m = m·Ud，两者都是严格的线性关系。在控制框图里，PWM 变换器就是一个比例环节加一个小延迟——这是它能做出高带宽电流环的根本原因。

01

线性

D 与输出成正比，增益不随工作点漂移；只要不进入过调制，控制器可以按线性系统设计，不必做增益调度。

02

高频

谐波被搬到载波频率附近。20 kHz 的载波，谐波群落在 20 kHz 上下，离基波 50 Hz 有四百倍的距离，一小段 LC 就能滤掉。

03

代价

每一次开关都要付一次开关损耗，损耗与 fs 大致成正比；桥臂必须留死区；高 du/dt 会带来 EMI、绝缘应力和轴承电流。

PWM 把“调压”换成了“调比例”，代价是把问题搬到了频域。

两个时钟 / 04 · 同一台电机04 / 09

04 系统级后果

平均电压相同，剩下的都不同

把两种方案接到同一台他励直流电机上，让平均电压相等、转速相等。平均值决定转速，剩下的脉动决定别的：转矩、噪声、发热，以及你要为平波电抗器付多少钱。

方案一：三相全控桥把 380 V 交流直接整成可调直流，靠改变 α 降压。方案二：不控整流得到 514 V 直流，再用 Buck 斩波器降到同样的电压。两者送到电枢的平均电压一模一样。

差别在电流上。相控的输出每 3.33 ms 才更新一次，电枢电流跟着 300 Hz 的电压包络起伏；PWM 每 50 µs 校正一次，电流几乎是平的。下面两条曲线用同一组电机参数（R = 0.05，τ = L/R = 40 ms）算出来。

稳态的纹波看完了，再看动态：如果转速指令突然变一下，两边分别要等多久才跟得上？

平均值决定“转到多快”，纹波决定“转得稳不稳、热不热、响不响”。

05 逐项比较

六项体检

把“控制特点”拆成六个可以量出来的维度。前五项是性能，第六项是代价——没有一项是白拿的。

两个时钟 / 06 · 代价06 / 09

06 账本

代价没有消失，只是换了位置

PWM 把“低次谐波”换成了“高频开关”，把“无功”换成了“损耗与干扰”。这些账要一项一项算清楚，才能说清一种控制方式适合什么场合。

01 / 损耗

开关损耗与 fs 一起涨

每次开通关断都要消耗 Eon + Eoff，功率损耗约等于 (Eon+Eoff)·fs。开关频率翻倍，这部分损耗大致翻倍；20 kHz 的 IGBT 变换器，开关损耗可能已经超过通态损耗。

02 / 死区

1～3 µs 的空白

同一桥臂上下管不能同时导通，必须插入死区。1～3 µs 的死区占 50 µs 周期的 2%～6%，输出电压出现畸变、基波幅值略有损失，低速小占空比时尤其明显。

03 / 干扰

du/dt 与共模电流

开关瞬间的 du/dt 可达每微秒数千伏，经电机与电缆的寄生电容耦合出共模电流，造成轴承电蚀、电缆末端电压反射，也让 EMI 滤波成为必需。

04 / 容量

单管的天花板

单只 IGBT 大约 6.5 kV / 1 kA 量级。要上到兆瓦、吉瓦，只能并联、串联或多电平；MMC 用数百个子模块叠出 ±800 kV，代价是器件数量和控制复杂度。

把开关频率当成一个旋钮拧一下，就能看到这笔账的两头。

相控仍然不可替代的地方。特高压直流输电的送端、电解电镀的大电流电源、静止无功补偿、大型轧机的直流传动——这些场合要的是单管容量、过载能力和每安培的成本，而不是毫秒级的响应。晶闸管在这些指标上仍然领先。

两者已经开始混合。混合直流把 LCC 换流站和 MMC 换流站接在同一条线路上：送端用 LCC 拿大容量和低损耗，受端用 MMC 拿灵活性和“不会换相失败”。谁也没有被淘汰，只是各自退到了擅长的位置。

选型不是选“先进”，是选哪一头的代价你付得起。

两个时钟 / 07 · 选型07 / 09

07 落到地上

先问三个问题

工程上很少问“哪个更先进”，只问“这个场合，哪一头的代价付得起”。三个问题基本能定位到答案。

Q1

功率多大？

百千瓦以下，PWM 几乎没有对手；兆瓦以上，先看器件容量够不够，再谈性能。

Q2

要不要四象限、要多快？

要回馈、要毫秒级转矩响应、要宽范围调速，只有全控器件能做到。

Q3

电网侧的无功和谐波谁管？

能装滤波和无功补偿，相控就还能用；装不了，就得让变换器自己把电流做干净。

误区 01

“PWM 一定更省电”

不一定。轻载时开关损耗占比很高，低频小功率场合相控反而更省；超大功率下晶闸管的通态损耗也低于同容量 IGBT。效率要按工作点算，不能按方式算。

误区 02

“相控只能整流”

相控还能逆变（α > 90° 配合反电动势）、交流调压、交交变频，也能做 SVC 和调光。它调的是相位，不是方向。

误区 03

“载波频率越高越好”

频率高，波形确实更干净、滤波器更小，但开关损耗、EMI、死区占比同时变差，还受器件和散热限制。载波频率是算出来的，不是挑出来的。

两个时钟 / 08 · 收束08 / 09

08 回到开头那句话

你手上那只开关，究竟能决定什么

相控用“何时开”换来了大容量与低损耗；PWM 用“开多久”换来了线性、快速与干净。

这两种控制方式并不是新旧替代的关系，而是对同一个问题的两种回答。器件给了你多少自由度，你就只能在这个自由度里做设计：半控器件只给你一个相位，全控器件多给你一个占空比，多出来的这一维，撑起了整个 PWM 家族。

所以回头看那些“特点”——余弦还是线性、等 3.33 ms 还是等 50 µs、谐波在 250 Hz 还是 19.8 kHz、电网看到的是滞后方波还是同相正弦——它们不是四条并列的结论，而是同一条因果链上的四个截面。
